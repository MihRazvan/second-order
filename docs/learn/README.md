# Second Order Docs

Second Order estimates what a copy-trader would actually receive from a source wallet's trade, and turns that estimate into a private ALLOW / RESIZE / BLOCK verdict.

This docs set is organized around the two things you actually use:

- the **utility** at `/`: a setup-utility page you drive with the keyboard
- the **stream API**: the service that turns Mobula observations into normalized events

If you are starting fresh, begin with [Start Here](./start-here.md).
